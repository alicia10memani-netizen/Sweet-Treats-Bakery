# Sweet-Treats-Bakery
A basic website project for Sweet Treats Bakery
## About the Project
Sweet Treats Bakery is a small bakery website project created for my WEDE5020w module.
The website provides information about the bakery, its products and services, and allows customers to make an enquiry.
## Website pages
The website contains the following pages:
1) Home
2) About Us
3) Services
4) Enquiry
5) Contact Us
## Products and Services
Sweet Treats Bakery offers:
- Birthday cakes
- Custom cakes
- Cupcakes
- Cookies
- Muffins
- Pastries
## Technologies Used
- HTML
- Notepad
- GitHub
## Project Purpose
The purpose of this project is to create a basic website for a small bakery and provide customers with useful information about the business.
## Images
Images were used to show some of the bakery products and make the website more appealing.
