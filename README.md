# Sweet-Treats-Bakery
A basic website project for Sweet Treats Bakery
## About the Project
Sweet Treats Bakery is a small bakery website project created for my WEDE5020w module.
The website provides information about the bakery, its products and services, and allows customers to make an enquiry.
## Website pages
The website contains the following pages:
1) Home
2) About Us
3) Services
4) Enquiry
5) Contact Us
## Products and Services
Sweet Treats Bakery offers:
- Birthday cakes
- Custom cakes
- Cupcakes
- Cookies
- Muffins
- Pastries
## Technologies Used
- HTML
- Notepad
- GitHub
## Project Purpose
The purpose of this project is to create a basic website for a small bakery and provide customers with useful information about the business.
## Images
Images were used to show some of the bakery products and make the website more appealing.

# Part 2 - CSS Styling and Responsive Design
This part of the project focuses on improving the Sweet Treats Bakery website using CSS and responsive design. I added an external CSS file and used it to style the different pages.

The changes I made include:
- Added an external style.css file.
- Added colour scheme and fonts.
- Added spacing and basic CSS styling.
- Used CSS Grid for the homepage layout.
- Added borders and shadows to improve the design.
- Added hover effects to the navigation and buttons.
- Added a more complete enquiry form.
- Added location and contact details to the Contact Us page.
- Added responsive design for desktop, tablet and mobile.
- Used relative units such as rem, %, and fr.
- Added responsive image settings.
# Testing
I tested the website using Microsoft Edge.
I tested the website at different screen sizes:
- Desktop
- Tablet
- Mobile

I checked the layout, images, navigation and enquiry form at the different sizes.
